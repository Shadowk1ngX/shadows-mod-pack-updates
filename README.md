# Shadows Mod Pack updates

This public repository hosts the update feed for Shadows Mod Pack. The Dev manager checks [appcast.xml](appcast.xml) on launch. The feed is empty until a tested installer is approved for release.

Installer downloads will be attached to GitHub Releases here. Every listed installer must be signed with the project's Ed25519 update key before its feed entry is published. The private key is not stored in this repository.

Dev build instructions are maintained locally in the Kotamon Dev project. The public Live installer is not changed by creating this feed.
